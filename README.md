# Laboratorio 5 - Programación

## ¿Qué significa `className` en React?

**className** en React basicamente es la misma etiqueta que se utiliza en HTML para dar identidades o clases a componentes que despues se 
puedan estilizar en CSS. 

---

## ¿los props tienen un limite?


No , los props en React no tienen un limite para usar dentro de un componente o a los componentes que fueran competentes
de hecho se puede pasar 

- cadenas de texto
- números
- funciones
- objetos
- arreglos 

entre otros componentes
